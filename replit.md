# HabitComb

A landing page for HabitComb, a honeycomb-shaped habit tracker app with animated UI built with TanStack Start and React.

## Run & Operate

- `npm run dev` — start development server on port 5000
- `npm run build` — build for production (outputs to `dist/`)
- `npm run lint` — run ESLint
- `npm run format` — format with Prettier

## Stack

- **Runtime:** Node.js 22
- **Framework:** TanStack Start (React + Vite 7)
- **Routing:** TanStack Router (file-based)
- **Styling:** Tailwind CSS v4
- **UI Components:** Radix UI primitives + shadcn/ui
- **Animation:** Framer Motion
- **Build config:** `@lovable.dev/vite-tanstack-config`

## Where things live

- `src/routes/` — file-based routes (TanStack Router)
- `src/components/` — React components (`HabitComb.tsx`, `StoreButtons.tsx`, `ui/`)
- `src/assets/` — static images (logo, etc.)
- `src/styles.css` — global CSS + Tailwind
- `vite.config.ts` — Vite config (wraps lovable config)
- `src/routeTree.gen.ts` — auto-generated route tree

## Architecture decisions

- Uses `@lovable.dev/vite-tanstack-config` which bundles TanStack Start, React, Tailwind, tsconfig paths — do NOT add these plugins manually or the app will break.
- Vite server overridden to use `host: "0.0.0.0"`, `port: 5000`, `allowedHosts: true` for Replit proxy compatibility.
- TanStack Start is an SSR-capable framework but this project uses it primarily for client-side rendering on the landing page.
- Cloudflare Workers deployment config (`wrangler.jsonc`) is included but unused in Replit.

## Product

- Marketing landing page for HabitComb mobile app
- Animated honeycomb habit grid visualization
- App Store / Play Store download buttons
- Features and preview sections

## Gotchas

- The `@lovable.dev/vite-tanstack-config` package defaults to port 8080 — the override in `vite.config.ts` is required for Replit.
- Requires Node.js ≥ 22 (TanStack Start packages enforce this engine requirement).
- `src/routeTree.gen.ts` is auto-generated by the TanStack Router plugin on `npm run dev` — don't edit manually.
